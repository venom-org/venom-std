# Security policy

## Supported versions

venom-std is in alpha. Only the latest commit on `main` receives security
fixes; there are no maintained release branches yet.

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue or pull request.
Use GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/venom-org/venom-std/security/advisories/new).

Include what you found, how to reproduce it, and the commit you tested. You can
expect an acknowledgement within 7 days. We will keep you updated while we work
on a fix and credit you in the advisory unless you prefer otherwise.
